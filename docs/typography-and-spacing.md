# Typography and spacing

Use a system sans-serif stack for interface text and a system monospace stack for code, identifiers and technical values. Establish a clear hierarchy through size, weight and spacing. Body text should remain comfortable to read; secondary labels can be smaller without becoming cramped.

Make page and section titles blue, with a restrained orange underline beneath headings. Align headings to the left on mobile. Allow long titles and technical values to wrap or scroll within their own region without causing page-wide horizontal overflow.

Use consistent spacing and modest corner radii. Dense reference tables can be compact; forms and workspaces can have more room. Keep related labels, values and controls close together, and leave enough separation between sections to make the hierarchy clear. Density must not hide information or reduce controls to difficult targets.

At narrow widths preserve useful existing patterns. For example, UnreleasedCommits retains its repository title and release followed by three side-by-side metric cells. Other projects should retain the responsive structure suited to their own content rather than copy that pattern indiscriminately.
