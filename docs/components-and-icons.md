# Components and icons

Use simple, consistent controls with modest rounding, subtle borders and visible hover and keyboard focus states. Choose one clear primary action for a task and use orange for primary icon actions. Secondary actions should remain recognizable without competing for attention. Preserve accessible names for icon-only buttons and links.

Use [Tabler Icons](https://tabler.io/icons) as the common icon family. Choose familiar outline icons at a consistent size and stroke weight, and use inline SVG or locally served assets. Do not replace meaningful data, provider marks or badges with generic icons. Decorative icons should be hidden from assistive technology.

Use native buttons, links, inputs and selects where possible. Give each input a persistent label and associate errors and help text with it. Show useful loading, empty, error and success states; explain what happened and how to recover. Copy actions should communicate success or failure.

Cards and panels organize related content without decorative colored lines on their top or left edges. Do not hide normal content behind new tabs or disclosures merely to achieve visual consistency.
