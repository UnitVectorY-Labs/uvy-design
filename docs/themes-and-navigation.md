# Themes and navigation

Offer light and dark themes with a clearly named icon toggle at the top right. Follow the operating system preference on a first visit and remember a person's explicit choice across visits. Ensure both themes have readable text, controls and focus indicators. The page should remain usable if JavaScript or storage is unavailable.

Keep each application's existing navigation and destinations. On mobile, place navigation on a separate line below the title and top-right theme icon so that it has room to wrap or collapse as appropriate. Keep navigation available and its toggle accessible, including its name and expanded state. Align mobile headings left.

Include a compact footer linking to the project's own source repository and license. Let the page layout place it at the bottom without covering content. Serve interface assets locally and use system fonts so the interface does not depend on third-party runtime requests.
