# UVY Design

Design guidance for UnitVectorY Labs projects. These principles give independent tools a recognizable family resemblance while respecting each project's purpose, content and workflows. This is a human-readable reference, not a dependency or a versioned asset package. Apply judgment in each application; maintain its own implementation and dependencies.

- [Foundations](docs/foundations.md): identity, layout and data colors.
- [Color](docs/color.md): blue, orange and accessible contrast.
- [Typography and spacing](docs/typography-and-spacing.md): hierarchy, headings and responsive behavior.
- [Components and icons](docs/components-and-icons.md): actions, controls and feedback.
- [Application header](docs/header.md): the common header pattern and responsive behavior.
- [Themes and navigation](docs/themes-and-navigation.md): appearance, navigation and footer.
- [Review](docs/review.md): practical checks for applying the guidance.

Open these standalone HTML examples directly in a browser; no server, build step, or external assets are required. Resize the window and use the theme button to explore responsive and light/dark appearances. Each file contains its own styles and behavior for inspection and adaptation.

- [Application header and navigation](examples/navigation.html): blue header, title, subtitle, theme control, and mobile navigation.
- [Forms and actions](examples/forms.html): fields, validation, buttons, and action hierarchy.
- [Panels, tables, and feedback](examples/panels.html): grouped content, a scrolling table, and common states.

These are illustrative starting points, not a dependency. Preserve each application's workflows and adapt the examples to its content.
